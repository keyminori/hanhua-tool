# 汉化翻译工作台（WebUI 版）

通用游戏文本机翻汉化工具 · 单机网页工作台。本分支是全新 WebUI 版（Python 标准库后端 + 单文件前端），
master 分支为旧版命令行工具，两者相互独立。

## 功能

- **翻译引擎**：百度「大模型文本翻译」+「通用翻译」双账号池，逐账号串行轮换（58003 同 IP 多 APPID 封禁安全模式），硬限 1 req/s
- **格式字节级保真**：TSV 逐行翻译，`\r\n`/`\n` 行尾、BOM、双 TAB、尾随空格、`<br>` 全部原样保留；原文列一个字节不动
- **术语表**：钉名翻译（伪标记防截断）、CSV 导入导出、改译名一键回写全部已产出文件（含缓存，幂等）
- **真实进度**：「产物即进度」逐行扫描待翻译/已翻译目录，行级完成度 + 剩余请求数 + ETA（实测/理论速率）
- **排队可视化**：▶ 翻译中 / ⏳ 排队文件实时显示
- **质量三闸门**：`<br>` 双向校验、低质判定（空回/占位/无中文/残留假名/截断）、补强重试梯度；失败行自动入低质队列
- **人工翻译通道**：低质队列人工改稿（落盘+缓存+台账+出队），manual_ov.json 全程留痕可回溯
- **事件留痕**：全部事件 JSONL 落盘（5MB 轮转），按级别/关键字查历史，SSE 实时流
- **文件校对 / 全文搜索**：单条保存、Ctrl+Enter、单句重译、`文件名#行号` 直达定位

## 启动

```bash
python server.py        # 默认 http://localhost:8731，PORT 环境变量可改
```

首次启动自动创建 `projects.json`（项目配置）与 `data/<项目>/.tt/`（缓存/状态/事件）。
代码与数据分离：`data/`、`projects.json` 不入库。

## 目录

- `server.py` —— HTTP 后端（路由 / SSE / 项目与账号与术语管理）
- `engine.py` —— 翻译引擎（双池账号、术语钉名、低质闸门、进度扫描）
- `index.html` —— 单文件前端工作台
- `repair_bad_lines.py` / `reset_project.py` 等为运维脚本
